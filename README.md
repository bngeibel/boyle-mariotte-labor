# Boyle-Mariotte-Labor

Interaktive Unterrichtssimulation mit zwei Zylindern, digitalen Manometern, Messwerttabelle und p-V-Diagramm.

## GitHub Pages
1. Repository genau `boyle-mariotte-labor` nennen.
2. Alle Dateien dieses Ordners hochladen.
3. Unter **Settings > Pages > Source** `GitHub Actions` auswählen.
4. Unter **Actions** auf den grünen Haken warten.

Die App erscheint unter:
`https://IHR-BENUTZERNAME.github.io/boyle-mariotte-labor/`

## Lokal testen
```bash
npm install
npm run dev
```
